# Classical Literature to Modern Slang Style Transfer (Seq2Seq)

Нейросетевая модель переноса стиля текста (Text Style Transfer), адаптирующая отрывки из русской классической литературы XIX века на современный интернет-сленг

## Стек технологий
- Python, PyTorch
- pymorphy3
- TorchMetrics, SacreBLEU

## Описание решения
- Выполнена токенизация и морфологическая лемматизация текстов с использованием `pymorphy3`, сформирован словарь объемом ~20.8 тыс. токенов
- Реализована архитектура `Encoder–Decoder` на базе рекуррентных сетей `GRU` с использованием `Teacher Forcing` и ограничением градиентов (`clip_grad_norm_`)
- Реализованы функции подсчета метрик `BLEU` и `chrF` (с учетом символьных n-грамм) и функция инференса `translate()` с фильтрацией повторов токенов
